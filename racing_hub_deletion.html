Data Deletion Request

App: Racing Hub: Idle Tycoon

This app does not use traditional user accounts. Some data may still be stored for leaderboards and analytics (for example an anonymous ID and display name).

How to request deletion

  1. Send an email to: YOUR_EMAIL@example.com
  2. Subject: Data Deletion Request - Racing Hub
  3. Include your in-game display/club name and approximate last play date (if known).

We will process valid requests and delete associated cloud data (such as leaderboard entries linked to your anonymous ID) within 30 days.

Note: Local game progress stored only on your device can also be removed by clearing app data or uninstalling the app.
